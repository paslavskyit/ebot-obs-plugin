# єБот для OBS

Плагін OBS Studio, який з'єднує ваш OBS з [єБотом](https://ebot.live): сцени, звук,
знімок сцени, сторож стріму, пауза нагород на сценах і бекапи працюють без пароля
WebSocket і без окремого вікна релею.

## Встановлення

1. Завантажте [`ebot-obs-setup.exe`](https://github.com/paslavskyit/ebot-obs-plugin/releases/latest/download/ebot-obs-setup.exe)
   і запустіть. Windows спитає — «Більше відомостей» → «Виконати однаково» (інсталятор не підписаний).
2. Відкрийте OBS: у меню **Доки** з'явиться «єБот». Натисніть «Підключити канал» і підтвердьте
   код у кабінеті єБота.

Вручну: розпакуйте `ebot-obs-windows.zip` у `%ProgramData%\obs-studio\plugins\`
(вийде `…\plugins\ebot-obs\bin\64bit\ebot-obs.dll`).

**Портативний OBS** (поруч з `obs64.exe` лежить `portable_mode.txt`) теку ProgramData не читає —
інсталятор там не допоможе. Розкладіть файли з `ebot-obs-windows.zip` у теку самого OBS:
`ebot-obs\bin\64bit\ebot-obs.dll` → `<OBS>\obs-plugins\64bit\`, а `ebot-obs\data\locale` →
`<OBS>\data\obs-plugins\ebot-obs\locale`. Оновлення — так само вручну.

**Вимоги:** Windows 10/11 x64, OBS Studio **31** або новіший (плагін зібраний проти SDK 31.1).
macOS і Linux — через скрипт-релей з кабінету.

## Пульт у доці (0.2+)

Після прив'язки док «єБот» показує пульт — музику, чергу нагород і рейд — у вбудованому
браузері OBS (obs-browser) у кольорах поточної теми OBS. Вхід без пароля: плагін relay-токеном
бере одноразовий код (`POST /api/obs/dock/handoff`) і відкриває `/api/obs/dock/enter?code=…`;
сам токен у посилання не потрапляє. Сесія пульта живе в окремому сховищі cookies доку і
стирається пунктом «Від'єднати OBS від каналу…» в меню «⋯». «Оновити пульт» перевідкриває його з новим кодом; зміна теми
OBS — теж. Без obs-browser док лишається як у 0.1 (стан і кнопки).

## Як це працює

Плагін — тонка труба: з'єднується з `wss://api.ebot.live/api/ws/obs-relay` (WinHTTP) і виконує
запити єБота через внутрішній API вбудованого obs-websocket (`src/obs-websocket-api.h`,
вендорено з obs-websocket). Дозволені запити — жорсткий список у `src/core.hpp`
(`OBS_CALL_ALLOWED_REQUESTS`), той самий, що в скриптах-релеях; паритет стереже тест
основного репо. Токен каналу зберігається під DPAPI у конфігу плагіна.

З 0.3:
- **Події пушем.** Сцена, старт/стоп стріму й запису (`outputs`) і мют мікрофона, який
  читає сервер (`input_mute`), ідуть пушем. Сервер не опитує OBS поза ефіром, а сторож
  прокидається одразу на старті стріму.
- **Запити — у двох робочих потоках** (звичайні й важкі). Запит, що пролежав у черзі
  довше 5 с (стільки сервер чекає відповіді), не виконується. Черги чистяться на кожне
  перепідключення.
- **`GetInputSettings`** віддає лише `url`, і тільки коли він веде на сервер єБота.
  URL алертів сторонніх сервісів несуть їхні токени.
- **Код 4002** («канал підключено з іншого ПК»): плагін не перепідключається сам. У доці
  з'являється кнопка «Підключити канал тут». Плагін заявляє це `?caps=replaced` у
  адресі сокета: клієнтам без цієї позначки сервер 4002 не шле.
- **Діагностика для підтримки** (з 0.3.1 — пункт меню «⋯»): версії, стан, причина
  останнього збою; токена там немає.

З 0.3.1 (аудит дизайну 25.10.2026):
- **Меню «⋯»** замість ⓘ і ✕: «Копіювати діагностику» й «Від'єднати OBS від каналу…».
  ✕ поруч з ↻ читався як «закрити док». Діалог від'єднання — кнопки «Від'єднати» /
  «Скасувати», Enter і Esc — «Скасувати» (`QMessageBox::question` ставив «Yes» за
  замовчуванням і англійські Yes/No).
- **Стан кольором теми**: «немає зв'язку» й «з іншого ПК» — `text-warning`, «канал
  від'єднано» й помилка прив'язки — `text-danger`.
- **Розмір шрифту OBS** (Налаштування → Вигляд) іде пульту параметром `fs` (px, 9–32):
  сторінка масштабується разом з OBS. Тема задає шрифт стилем, тож розмір читається з
  поліруваного віджета дока, а не з `QApplication::font()`.
- **Прив'язка**: під кодом — посилання «Сторінка не відкрилась?» на сторінку
  підтвердження; код — Cascadia Mono / Consolas замість Courier New.
- «Не вдалося відкрити пульт» — з посиланням «Спробувати ще раз» прямо в тексті.
- Інсталятор — з іконкою єБота.

## Розробка

- Збірка — лише в CI (`.github/workflows/windows.yml`, шаблон `obs-plugintemplate`).
- Чиста частина тестується без OBS: `g++ -std=c++17 -Isrc tests/core_test.cpp src/core.cpp -o core_test && ./core_test`.
- Локальний сервер: задайте `EBOT_SERVER=http://localhost:8000` перед запуском OBS.
- Реліз: версія в `buildspec.json`, потім тег `vX.Y.Z` — CI викладе інсталятор, zip і `latest.json`.
